# Third-party notices

This extension includes bundled JavaScript and a Go language server. The
`third_party_licenses/INDEX.md` file in the VSIX lists their runtime dependencies
and includes the license and notice files supplied with them. That directory is
generated by `pnpm run package:vsix` from the installed packages and Go modules.

## elkjs

The navigation graph bundles `elkjs` 0.12.0. Its source code is available under
the Eclipse Public License 2.0 at
<https://github.com/kieler/elkjs/tree/0.12.0>. The original license text is
included at `third_party_licenses/npm/elkjs/0.12.0/LICENSE.md`. The source
repository includes the preferred source form and build instructions.

The separate Go ports in `third_party/` of the source repository are bundled
into the server binary. Their licenses and notices are included in the generated
directory as well.
